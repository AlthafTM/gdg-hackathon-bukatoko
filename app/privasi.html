Siapa yang mengelola

BukaToko dikembangkan oleh tim GDGoC ITB Stack Hackathon pada repositori gdg-hackathon-bukatoko. Data pada layanan aktif dikelola oleh pengelola server tempat layanan tersebut berjalan. Halaman ini menjelaskan perilaku implementasi saat ini, bukan janji adanya fitur yang belum tersedia.

Data yang diproses

Saat mendaftar, server menyimpan nama tampilan, email, hash kata sandi, status verifikasi, dan waktu pembuatan akun. Aktivitas dapat mencakup barang, foto, kota, permintaan, simpanan, pencarian tersimpan, suka, komentar, tanggapan, pesan, tawaran, serah terima, ulasan, notifikasi, dan laporan moderasi. Server juga memproses alamat IP untuk pembatasan permintaan; log akses dapat memuat IP, metode, dan alamat halaman yang diminta.

Tujuan dan pilihanmu

Data digunakan untuk menjalankan akun dan fitur yang kamu pilih, menampilkan katalog, menghubungkan pengguna, serta mencegah penyalahgunaan. Kamu dapat melihat katalog tanpa akun. Menulis konten dan menggunakan fitur akun memerlukan masuk. Izin lokasi bersifat opsional; kamu selalu dapat memilih kota secara manual.

Data publik dan akses

Nama tampilan, barang beserta foto dan kota, profil, permintaan, komentar, tanggapan, dan ulasan dapat diakses publik. Email, simpanan, pesan, serta tawaran tidak ditampilkan sebagai katalog publik. Moderator dapat melihat laporan dan menjalankan moderasi. Pengelola server memiliki akses teknis ke basis data, berkas unggahan, dan log. Jangan mengunggah data sensitif ke layanan ini.

Cookie dan penyimpanan perangkat

Cookie bk_session menjaga sesi masuk hingga 30 hari dan tidak dapat dibaca JavaScript. Cookie bk_csrf membantu melindungi perubahan data. Keluar mengakhiri sesi dan membersihkan cookie tersebut. Browser menyimpan tema, bahasa, dan hingga delapan ID barang terakhir dilihat di localStorage; kata kunci terakhir disimpan di sessionStorage. Hapus data situs lewat pengaturan browser untuk membersihkannya. Kode aplikasi tidak memasang pelacak iklan atau analitik pihak ketiga.

Lokasi dan penyedia lain

Jika kamu menekan Gunakan lokasi saya dan memberi izin, browser menentukan koordinat untuk memilih kota terdekat di perangkat. Kode aplikasi tidak mengirim atau menyimpan koordinat tersebut ke API; hasil filter memakai nama kota. Kamu dapat mencabut izin lewat browser. Font dan foto referensi dibundel sebagai aset situs. Hosting memproses permintaan web; tautan GitHub dan layanan luar mengikuti kebijakan masing-masing setelah dibuka.

Penyimpanan dan keamanan

Layanan aktif menyimpan data dalam basis data server dan berkas unggahan. Belum ada jadwal penghapusan otomatis untuk semua jenis data atau halaman hapus akun mandiri. Menghapus barang tidak berarti seluruh pesan, log, atau cadangan terkait ikut terhapus. Kata sandi di-hash, tetapi pesan tidak dienkripsi ujung ke ujung. Mode email demo dapat menulis kode verifikasi atau reset ke log server, dan pada konfigurasi tertentu menampilkannya di layar. Jangan gunakan kata sandi yang dipakai pada layanan penting lain.

Hak dan permintaan terkait data

Kamu dapat menyunting atau menghapus konten milikmu pada fitur yang tersedia, menghapus simpanan, keluar, dan mencabut izin lokasi. Untuk permintaan akses, koreksi, atau penghapusan data yang tidak tersedia di layar, hubungi pengelola melalui portal bantuan dan minta jalur privat tanpa mengirim identitas di laporan publik. Tim perlu memverifikasi kepemilikan akun sebelum menangani permintaan; belum ada alur otomatis untuk permintaan tersebut.

Laporan bug dan pembaruan

Formulir bug membuat pratinjau lokal. Isinya baru dibawa ke GitHub saat kamu memilih Lanjut ke GitHub; laporan menjadi publik setelah kamu mengirimnya di sana. Tidak ada unggahan log, tangkapan layar, cookie, atau data akun secara otomatis. Kamu juga dapat mengunduh laporan teks. Tanggal pembaruan kebijakan ditampilkan di atas halaman ini.
