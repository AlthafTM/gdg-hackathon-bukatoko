# Bukatoko 0.5.2

## Summary

Restore the self-contained GitHub Pages UI preview so browsing fetches bundled sample data instead of depending on the separately hosted Instabox API.

## Changes

- Publish `_site` rather than the cross-origin `_site-live` artifact. Keep the optional connector export only as a separate test fixture.
- Add an `--app-url` option that provides a direct link to Instabox without changing the preview's data source or enabling remote API requests.
- Keep catalog search, filters, details, profiles and wanted requests backed by the same-origin `assets/preview-data.json` snapshot.
- Add deployment-artifact regression coverage and same-origin CSRF headers for JSON writes and uploads when using the frontend with the existing backend contract.
- Correct connection guidance after inspecting the moderator-capable feature-branch source. Do not require replacing the existing backend; do not attribute findings from main's older server to an unverified deployed revision.

## Validation

- Static checks passed for JavaScript syntax, Python exporter AST, selected Pages artifact, the app-link option, preview data URL construction and Git whitespace.
- Remote main was inspected before release preparation; no new collaborator commits or overlapping paths were reported.
- Runtime tests were not rerun locally because the installed security-audit skill requires an execution sandbox not available on this host. The authorized push runs the configured repository, export, frontend and connection checks in GitHub Actions; observed outcomes are reported separately.

## Known limits

- The Pages preview is read-only sample data. Login, selling, uploads, messages and offers require opening the separate Instabox application; this release does not claim a working cross-origin API connection.
- No backend source, hosted process, database, uploaded files or moderator account was changed. The user-supplied live-app URL remains a link and may become unavailable independently of the preview.
- Runtime connection checks use dummy/mocked fixtures; they do not verify the deployed backend. Live backend behavior and browser visual checks remain unverified.
