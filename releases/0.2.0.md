# Bukatoko 0.2.0

## Summary

Refresh the marketplace UI with the supplied BukaToko logo, consistent typography and clearer navigation across the full Python app and read-only Pages preview.

## Changes

- Preserve the supplied combined SVG logo and use its cart symbol as the favicon.
- Bundle Exo 2 with its SIL OFL license; use one type family for headings, forms and prices.
- Refine the purple, lavender and green tokens, restrained introductory gradient, spacing, prices and native select controls in both themes.
- Add labeled SVG navigation/category icons and restore the previously empty category links.
- Add mobile bottom navigation, safe-area spacing and separate tablet layout rules.
- Forward the condition filter to the Python listing query and add a regression check.
- Include the logo, font and license in the allowlisted Pages build. Document design decisions and the remaining visual checks.

## Validation

- 39 API smoke checks passed against a temporary copy/database, including authentication, uploads, listing creation, offers, messaging, reviews and condition filtering.
- Seven pages and six assets returned HTTP 200 from the Python server.
- Four Pages export/adapter tests passed, including public-fixture privacy, font/license/logo export, filtering, navigation URLs and rejection of writes/private endpoints.
- JavaScript syntax, relative HTML links, unchanged supplied logo bytes and Git whitespace checks passed.
- Computed token contrast passed in both themes: minimum tested text ratio 5.16:1 and control-boundary ratio 3.45:1.

## Known limits

Browser access was denied for both the local and public preview origins. Visual review, mobile rendering, console inspection and browser click-through remain unverified; see docs/UI-REVIEW.md. Publication was explicitly authorized with this limitation recorded. GitHub Pages remains a read-only sample preview; the full account and transaction flows require the Python server. Exo 2 is an openly licensed alternative, not the requested inpin font itself.
