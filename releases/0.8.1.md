# Bukatoko 0.8.1

## Summary

Use the same public like and comment interactions on items and wanted posts.

## Changes

- Show passive like and comment counts together below card metadata.
- Open the item detail or expand the wanted post to like or comment. Wanted counters update after successful writes.
- Place share and report at the right end of the item detail toolbar.
- Use likes for new public reactions. Existing private saved items remain available in Account.

## Validation

- 32 frontend tests passed, including passive counts and wanted interactions.
- 166 API and page checks passed against the disposable backend.
- Verified wanted expansion, catalog counters and item detail toolbar in a 390 px browser viewport.

## Known limits

- GitHub Pages shows example data. Account actions require the connected app.
- The report action uses the existing item moderation workflow.
