# Bukatoko 0.6.2

## Summary

Separate theme switching from page transitions and refine marketplace controls and wanted-card actions.

## Changes

- Define one CSS circular reveal before snapshot capture, keep the old snapshot opaque, cancel theme-time group/page fades, and retain the previous canvas colour behind the overlay. Remove the second JavaScript animation started after View Transition readiness; preserve reduced-motion and unsupported-browser fallbacks.
- Reduce violet/lime hover outlines to 1px and general keyboard focus to 2px, preserve the 1px input focus, correct the legacy filter-summary radius and preserve the seller panel's positioning.
- Use one rounded chevron for native select controls, vertically centred with consistent right padding in both themes.
- Place like, comment and reply icons with counts at the lower right of wanted cards. Keep accessible text, pressed/expanded states and existing API payloads. Expanded comment/reply panels sit outside the action toolbar.
- Rebuild the React icon registry, refresh asset cache keys, update hosting guidance and add wanted-action regression coverage to frontend CI.

## Validation

- React/Tailwind production build passed. All 36 Node UI, locale, motion, React, location, wanted-action, Pages and API-connection cases passed.
- Disposable backend suites passed 53 API smoke, 70 feature and 40 structural UI checks. No backend code or application data changed.
- Local browser samples checked both theme directions with the old snapshot at opacity 1, no old-layer animation and one theme-circle animation. Checked dropdowns and wanted actions at desktop, 390px and 768px, expanded panels and English labels. No console errors appeared in sampled screens.
- Repository/release helper unit tests and staged release/overlap guards are checked before publication; GitHub Actions and release assets are verified after pushing.

## Known limits

- Browser sampling is not a frame-by-frame proof across all browser engines/devices. Circular snapshots depend on View Transition support; reduced motion bypasses the animation.
- Pages remains a read-only preview. Instabox deployment was explicitly cancelled by the user; this release changes no hosted backend, database or uploads there.
