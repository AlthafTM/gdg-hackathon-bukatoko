# Bukatoko 0.1.1

## Summary

Publish the existing Bukatoko app as a read-only GitHub Pages preview and credit its contributors.

## Changes

- Add an allowlisted static build, public sample snapshot and read-only API adapter; preserve the existing app palette and Python server behavior.
- Deploy tested frontend artifacts through pinned official GitHub Pages actions.
- Credit DHO212 and ColdCloverr and document preview setup, capabilities and limits.
- Make `main` the default working and publishing branch; separate branches require an explicit user request. Keep explicit publishing authorization and remote-overlap guards.

## Validation

- Both merged PRs: 38 API smoke checks, 20 repository workflow tests, JavaScript syntax and release metadata validation passed.
- Pages build and four Node test cases verify fixture privacy, export allowlist, filtering/sorting/pagination, details/profiles, project-subpath URLs and rejection of write/private requests.
- Regenerated full research TXT and integrity manifest after README changes; package verification passed.

## Known limits

GitHub Pages is read-only and contains sample data and placeholder images. Accounts, uploads, posting, saving, offers, messages, reviews and moderation actions require the local Python server. This publication is not a production backend or a security audit.
