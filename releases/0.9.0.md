# Bukatoko 0.9.0

## Summary

Prepare BukaToko for a persistent cloud VM and add profile photos and automatic language selection.

## Changes

- Add deployment configuration for a loopback Python service behind Caddy HTTPS. Cloud mode uses persistent database and upload paths, Secure cookies, and optional STARTTLS SMTP.
- Show avatar, username and posting time on item and wanted cards. Add profile photo uploads in Account.
- Use browser language preferences and fall back to English when needed.
- Let users close their own wanted posts from Account. Revoke the active session on logout.

## Validation

- 172 local API and page checks, 47 frontend and export tests, and a local cloud mode test passed.
- Reviewed the item and wanted layouts at a 390 px viewport.

## Known limits

- Cloud activation requires a provisioned VM, SSH access and a hostname. Live HTTPS and SMTP have not been verified.
- GitHub Pages shows the read-only example catalog.
