# Bukatoko 0.0.1

## Summary

First tracked project release: research references and collaboration/release foundations for the GDGoC ITB Stack Hackathon team.

## Changes

- Preserve the Carousell Indonesia research package: PDF, full plain text, screenshots, official sources, bundle identities and compressed REA evidence.
- Document Bukatoko's selling and wanted-item requests with price ranges.
- Add `AGENTS.md`, contributor workflow, remote-change/overlap checks, staged release validation and an optional local pre-commit guard.
- Establish patch/minor version increments, a changelog and automatic tagged GitHub Releases after approved updates reach `main`.
- Include release PDF/TXT downloads and retry-safe publication without replacing existing tags or assets.
- Regenerate the plain-text repository context and write generated text/manifests with consistent LF line endings for reproducible verification.

## Validation

- All 20 standard-library unit/integration tests passed locally, including simulated collaborator pushes and idempotent release publication.
- Working-tree release metadata validates against the freshly fetched pre-versioning `origin/main`; staged metadata is checked immediately before the authorized commit.
- The REA package passes hash/decompression/PDF/text checks after regenerating its plain text with the updated repository context.
- Observe the first GitHub Actions check and release run after publishing; the final task report records the actual outcome.

## Known limits

- This release provides research and workflow foundations, not an implemented marketplace app.
- REA native app internals and authenticated transactions remain unverified; DOM exports are partial as documented.
- File-overlap checks cannot guarantee absence of semantic conflicts or prevent a new remote commit after the check. Ordinary Git push rejection and reviewed PRs remain necessary.
- Branch protection and hook installation are not enabled automatically. AI commit authorization is a conversation rule, not cryptographic enforcement.
