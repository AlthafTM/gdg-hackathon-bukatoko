# Bukatoko 0.7.1

## Summary

Mobile navigation now floats above the bottom edge and keeps selected labels at normal weight.

## Changes

- Inset the mobile navigation 12 px from each side and 12 px above the device bottom safe area, with a rounded surface and shadow.
- Reserve extra bottom space so page content can scroll clear of the floating navigation.
- Keep active and inactive mobile labels at font weight 400; retain the lime selection indicator.
- Refresh HTML asset cache keys and document the navigation appearance.

## Validation

- Browser check at 390 x 844: measured 12 px bottom gap, 24 px wrapper radius, no horizontal page overflow, and font weight 400 before and after changing the active screen.
- Visually checked the floating navigation on the local preview.
- Python repository workflow/package suite: 22 tests passed.

## Known limits

- Device safe-area spacing uses CSS env(safe-area-inset-bottom); a physical notched phone was not available for this check.
- Instabox deployment is outside this update; the frontend changes are published through GitHub Pages and the release package.
