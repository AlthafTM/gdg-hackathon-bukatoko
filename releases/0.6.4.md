# Bukatoko 0.6.4

## Summary

Keep task pages focused and simplify the account entry screen, with consistent spacing around nearby catalog controls.

## Changes

- Reuse the page-level catalog-tools guard to omit the main search bar as well as quick categories on Wanted, Sell and Account. Retain normal header/mobile navigation and catalog search elsewhere.
- Remove the long guest-account explanation and separate bordered panel. Show the account heading, existing short description and login/register button directly, preserving the existing authentication controls and account gate.
- Give catalog location controls 24px block spacing and aligned desktop columns; stack the hint beneath the button on small screens. Remove the legacy filter-summary top margin that added an extra mobile gap.
- Refresh frontend asset cache keys. No backend code, API contracts or stored data change.

## Validation

- All 36 Node frontend, locale, motion, React, location, wanted, public export and API-connection regression cases passed.
- Disposable backend tests passed 53 API smoke, 70 feature and 40 structural UI checks. All 22 repository/release unit tests passed.
- Local preview browser checks confirmed zero search bars/quick category strips on all three task pages, the simplified account entry on desktop/390px, and catalog spacing with a single 24px gap and no extra filter-summary margin. Sampled screens had no horizontal overflow or console errors.
- Staged metadata and collaborator-overlap guards run before the authorized commit. GitHub Actions and release assets are verified after pushing.

## Known limits

- Pages remains a read-only sample preview; login and other writes require the existing Python backend. Local preview checks do not verify hosted authentication.
- Instabox deployment remains cancelled and its files/database/uploads are unchanged.
