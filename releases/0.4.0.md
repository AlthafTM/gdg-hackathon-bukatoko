# Bukatoko 0.4.0

## Summary

Polish BukaToko's rounded typography, search layout and controls, complete the Indonesian/English UI localization layer, and apply the requested browser identity.

## Changes

- Use locally hosted Nunito with its SIL OFL license, stronger headings, rounded controls, consistent card radii and subtle hover glow.
- Add shared desktop search, fix the keyword input's icon padding and align the first catalog card with the filter panel, including filtered states.
- Add reversible UI localization for all seven pages, dynamic UI statuses, accessible labels and backend error messages; preserve typed values, option wire values and user content.
- Replace built-in generic image placeholders with labeled contextual SVG illustrations; retain real uploaded photos.
- Replace visible required-field wording with an asterisk and a form legend while retaining required semantics.
- Set browser titles and the homepage heading to BukaToko - Jual apapun disini.; use the supplied cart symbol as an adaptive-color favicon with a versioned URL.
- Keep product Open Graph metadata independent of browser titles and include regression coverage for this backend route.

## Validation

- 40 API smoke checks passed using a disposable copy/database, including the branded product-page title and Open Graph metadata.
- 12 Node test cases passed for Pages export, card/theme behavior, contextual illustrations, localization coverage and form/user-content preservation.
- JavaScript syntax and release/remote-overlap checks passed. The preceding UI check also verified seven HTML documents for balanced markup, unique IDs and valid relative asset links.

## Known limits

Actual browser rendering, favicon appearance, language wrapping, hover effects and click-through remain unverified because browser access was previously denied. No full visual or performance pass is claimed. Localization tests use a minimal DOM fixture and do not replace browser tests; user-written descriptions/messages remain in their original language. GitHub Pages is read-only; full account, upload and transaction flows require the Python server. See docs/UI-POLISH-REVIEW.md.
