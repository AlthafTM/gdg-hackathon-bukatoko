# JualinAja 0.10.0

## Summary

JualinAja is the new name of the marketplace and its GitHub repository.

## Changes

- Introduce a two-color Nunito wordmark and an overlapping n/A favicon.
- Show the seller or requester and posting time above and outside each card.
- Update site titles, legal pages, support links, email subjects and release packaging.

## Validation

- 47 frontend and Pages checks, and 172 API, feature and UI checks against the WSGI app.

## Known limits

- GitHub Pages remains a read-only preview; live accounts and listings use PythonAnywhere.
- Existing database paths and session identifiers are kept for compatibility.
