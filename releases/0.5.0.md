# Bukatoko 0.5.0

## Summary

Refresh marketplace navigation, search, photography and theme motion, and prepare the GitHub Pages frontend to use the supplied Instabox backend.

## Changes

- Use deep charcoal, electric violet and acid lime with rounded controls, consistent card radii and a wider desktop layout/filter panel.
- Align wanted-board headings and form panels; place saved-search actions below their filters; add an explicit Home navigation item and quick category switching that preserves applied filters.
- Replace seed-listing illustrations with 14 locally served Pexels reference photographs. Include source/photographer/license/hash records and bilingual reference labels; retain uploaded seller photos as the first choice.
- Initialize saved themes before stylesheet loading, remove the whole-grid entry fade, and add reduced-motion-aware dialog/scroll effects and circular View Transition theme reveal.
- Route configured API requests, uploads and uploaded photos to the user-provided Instabox origin. Keep share links on the frontend and retain an unconfigured read-only export mode.
- Add opt-in exact-origin CORS, write-origin validation and Secure/HttpOnly/SameSite=None cookies for cross-site hosting. Document backend setup and provide a direct-app link for browsers blocking third-party cookies.
- Prepare the Pages workflow to build/check read-only and connected artifacts, then deploy the connected artifact. Add connection/export/photo regression coverage.

## Validation

- Earlier pre-photography/palette/connection baseline: 41 API smoke checks and 17 Node cases passed. These are historical baseline results, not a runtime pass for this release.
- Latest local source checks: JavaScript/test syntax via node --check, Python AST parsing, seven HTML documents' IDs/relative asset links/theme bootstrap order, 14 JPEG file hashes, selected text contrast pairs and Git whitespace checks passed.
- Remote main was inspected before release preparation; no incoming commits or overlapping paths were reported. Release metadata and staged content are checked before the authorized commit/push.
- New runtime tests and both exports have not been executed locally: the installed security-audit skill requires an OS-enforced execution sandbox unavailable on this host. GitHub workflows run the configured publication/build checks after the authorized push; their actual results are reported separately.

## Known limits

- The remote Instabox process must receive the updated server.py and documented environment configuration, then restart. Publishing Pages does not deploy or restart that backend. Live API/CORS/session behavior is unverified; no deployed backend probes were performed.
- Browsers blocking third-party cookies can require the direct backend-hosted app. Tunnel URLs may expire or change; see docs/BACKEND-CONNECTION.md.
- Browser visual checks remain unverified following the earlier denied browser access. Circular reveal requires View Transitions; other browsers fade colors, and reduced motion updates immediately.
- Source review found unresolved logout server-session revocation and cross-owner photo reuse/deletion defects. Connection setup does not remediate those findings or certify this demo for sensitive data.
