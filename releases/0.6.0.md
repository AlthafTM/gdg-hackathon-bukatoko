# Bukatoko 0.6.0

## Summary

Integrate the existing moderator-capable backend branch with the publicly served frontend integration, then add React catalog rendering, compiled Tailwind utilities and responsive visual/motion improvements.

## Changes

- Merge feat/bukatoko-0.2 history while preserving main's published release metadata. Resolve frontend integration using read-only copies of the public Instabox HTML/CSS/JS; record source hashes and scope limitations.
- Retain existing same-origin authentication/CSRF, notifications, transactions, verification, editing, moderation, social features, wanted replies and search enhancements. Fix Open Graph insertion independently of the branded title. Remove the earlier experimental CORS variant from the unified backend; do not deploy over the active Instabox process.
- Render all catalog lists through keyed React components with one root per list and explicit disposal. Compile prefixed Tailwind utilities locally without Preflight; pin dependencies and include third-party notices.
- Use full 4:3 catalog photo frames, rounded icons, violet/lime hover glow, more acid-lime navigation/action accents, compact mobile/tablet typography and folding filters through 1024px.
- Slow theme reveal to 900ms with a 120ms delay; add short press feedback and dialog exit fade. Initialize locale earlier, isolate React translation ownership, avoid late font replacement and use supported native page transitions with a stable header. Respect reduced motion.
- Keep Pages as a self-contained read-only preview, with additional public preview read routes. Exclude server-only moderation/404 pages from its artifact.
- Add a disposable integrated-app test runner and a deterministic frontend-only ZIP package, attached alongside PDF/TXT by the release workflow for the hosting collaborator.

## Validation

- Production React/Tailwind build passed. The Node UI/export/connection/React regression suites passed during preparation; fixture API suites passed 53 smoke, 70 feature/lifecycle and 40 structural checks. Final workflow totals are reported after publication.
- Repository/release unit checks passed during preparation; new packaging and optional-attachment coverage is included in the final checks.
- Authorized local browser checks sampled seven public screens at 390/768/1440 in both themes without horizontal overflow. Mobile filtering, keyword search, card-language updates, theme switching and navigation were exercised. Indonesian switching persisted on subsequent navigation; list/form tops aligned on the wanted board.
- A separate disposable same-origin backend browser fixture retained login after reload, displayed all eight account tabs, opened notification/transaction states and the moderator page without console errors. No live credentials or production application data were used.
- Remote main and the feature branch were inspected before integration; overlap/release guards run again before the authorized merge commit and push. GitHub workflow results are reported separately after publication.

## Known limits

- React migration is progressive: catalog lists are React components; the compatible non-catalog controllers remain. No measured FPS, Lighthouse score or net performance improvement is claimed.
- The collaborator's private uncommitted index/backup was unavailable. The feature-branch backend/tests and publicly served integration were reviewed and merged, not an unseen private patch.
- This release does not update the running Instabox filesystem or restart its service. The collaborator with hosting access must apply the frontend-only ZIP after preserving their pending work and current frontend. The active DB/uploads are unchanged.
- Pages remains sample-data/read-only. Live operations belong to the same-origin Instabox app. Browser checks are samples and do not exhaust every administrative action; native navigation/theme effects depend on browser support.
- Demo verification/reset codes remain part of the existing no-email demo behavior. Regression checks are not a comprehensive security audit or production-readiness certification.
