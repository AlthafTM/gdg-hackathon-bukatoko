# Bukatoko 0.6.3

## Summary

Simplify secondary-page navigation and make home/account surfaces consistent with the marketplace cards.

## Changes

- Omit the fast category strip on Wanted, Sell and Account while preserving primary navigation and search.
- Centre the account page within a narrower container, round and centre its login panel, align the account summary and restore a consistent statistics grid and rounded account tabs across breakpoints.
- Hide the visual catalog result count beneath All items, retaining its live update for assistive technology and existing filtering logic.
- Widen the shirt body and sleeves in both the React icon registry and fallback renderer without changing the category identifier.
- Replace the full-width home introduction gradient with a solid rounded card inside the standard page gutters. Retain the wanted preview and its calls to action, with consistent internal mobile spacing.
- Refresh frontend asset cache keys; no backend code, API contracts or application data change.

## Validation

- Production React/Tailwind compilation passed. All 36 Node UI/locale/motion/React/location/wanted and rebuilt public export/connection cases passed.
- Disposable backend suites passed 53 API smoke, 70 feature and 40 structural UI checks.
- Local browser checks confirmed equal desktop home-card gutters, a solid background, centred rounded guest/login account views, all eight authenticated tabs and the account statistics grid. Sampled 390px wanted/sell/account screens had no horizontal overflow and no fast category strip. Catalog retains its accessible hidden count.
- All 22 repository/release unit tests passed, along with staged metadata and overlap guards. GitHub Actions and release assets are verified after pushing.

## Known limits

- GitHub Pages remains a read-only sample preview; authenticated account operations require the Python backend. Browser checks used a disposable local database, not production data.
- Instabox deployment remains cancelled. This publication does not replace its running files, database or uploads.
