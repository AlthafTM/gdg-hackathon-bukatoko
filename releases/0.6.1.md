# Bukatoko 0.6.1

## Summary

Refine marketplace interactions and prevent the new theme snapshot appearing before its circular reveal. Add optional device-location city selection and a consistent missing-page screen while preserving the existing same-origin backend contract.

## Changes

- Hold the new theme snapshot at a zero-radius clip before View Transition readiness, preserve the reveal delay, and ignore overlapping toggle clicks. Clean up temporary CSS state on completion or failure; retain reduced-motion and unsupported-browser fallbacks.
- Use a tighter, stronger violet/lime hover glow and a 2px gradient outline, with a thinner 1px focus outline on form controls. Make search submit buttons lime and separate wanted-request budgets from their action row.
- Redraw fashion and sports icons with rounded strokes, use Fashion in both locales while preserving the `fesyen` API identifier, and normalize required-field note spacing.
- Request geolocation only after selecting Use my location. Match an approximate supported city without storing or transmitting coordinates; retain manual selection and denial/error states. Filter the wanted board locally using the existing API response.
- Style the 404 page with the normal shell, language/theme controls and clear recovery links. Include it in the Pages export with a repository-relative base so nested missing addresses resolve assets correctly.
- Add location and theme regression coverage to frontend CI; document existing hosting access requirements and a frontend-only handoff for the collaborator's AI.

## Validation

- Production React/Tailwind compilation passed. All 33 Node UI, React, locale, motion, location, Pages-export and API-connection regression cases passed.
- Disposable Python backend suites passed 53 API smoke, 70 feature and 40 UI structural checks. Backend code, database and uploaded photos are unchanged by this patch.
- Local browser checks exercised both directions of the circular reveal, city filtering, wanted-form spacing, English/Indonesian 404 content, nested missing routes and responsive layouts at 390px and 768px, plus the desktop layout. No console errors appeared in the checked screens.
- All 22 repository/release helper unit tests passed. Overlap/release metadata checks run before the authorized commit. GitHub Actions results and release assets are verified after pushing.

## Known limits

- Location results use approximate city centres (12 supported cities within 80km), not exact item-distance ranking. Wanted filtering covers the endpoint's latest 60 requests. Permission can be denied and manual selection remains available.
- Circle transitions depend on browser View Transition support; reduced-motion settings bypass them. Browser sampling and regression tests do not prove behavior on every device.
- GitHub Pages remains a read-only sample preview. Publishing this release does not update Instabox files. Deployment to that existing server requires terminal/workspace or SSH access from its owner; moderator credentials do not provide filesystem access.
