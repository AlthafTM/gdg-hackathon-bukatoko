## App identity and regional boundary

LTD., ads and in-app purchases. Page snapshot displayed update 11 September 2026. This establishes public store identity and declared feature availability, not a binary version or runtime test.

The description explicitly lists Indonesia among served markets. It limits Official Delivery to Singapore/Hong Kong/Malaysia, Buyer Protection and Certified programs to Singapore/Malaysia/Hong Kong, and photo AI to Singapore/Malaysia/Hong Kong/Philippines. Video AI is Singapore. Consequently those features must not be assigned to the Indonesia reconstruction by default. Android SDKs, permissions, transport protocol, storage and signing certificate remain unknown.

**A02 iOS.** [Indonesia App Store](https://apps.apple.com/id/app/carousell-snap-sell-chat-buy/id548607187) resolves title “Carousell: Snap-Sell, Chat-Buy,” numeric identity `548607187`, Carousell Pte. Ltd. Public snapshot lists version `2.483.0` with relative age “5 days ago,” 288.4 MB, iOS 13.1+, Indonesian among five languages, free with in-app purchases. Treat relative version age and metadata as store-snapshot facts, not a proved currently installed build. Do not back-calculate a release date from a cached relative age.

Store purchase catalog includes Coins, a 3-Day Bump, and Starter/Growing CarouBiz entries priced in rupiah. These establish catalog entries, not live Indonesia entitlement or current package price. The description repeats the regional limitations above. Release notes reference auctions starting with Singapore trading cards, and Live in Singapore/Hong Kong, so their existence in this Indonesia storefront does not prove Indonesian availability. Bundle ID/native UI implementation/runtime internals remain unknown.

## Evidence quality and remaining questions

Observed here means public page text retrieved via web tools; it does not mean native app use. Official Indonesian help is preferable to old English buying guides that generalize payment behavior across countries. Store marketing combines markets, while per-feature footnotes and local help delimit availability. Store privacy declarations describe developer claims, not a security assessment. No cryptographic or traffic conclusions should be drawn from the Google Play data-safety label alone.

Required future native verification: install from official store on user-selected device; record build/package identity and region; inspect guest and authenticated navigation; exercise listing draft, offer/review gates, saved-search limit and permissions using test accounts; capture permitted request metadata and decompile a legitimately acquired APK with REA Android tools. Current evidence cannot support native screen pixel measurements, exact tab order, SDK inventory, API identity, push-provider identity, local database schema, offline behavior, or binary protections.
